actividad integradora 3
Para desplegar la actividad se debe instañr los siguiente:
Instalar Xampp
crear la base de datos db_sistema_web 
ingresar al phpmy admin
entrar a la base de datos creada
usar la herramienta comandos
copiar el contenido del archivo db_sistema_web
Se creara los campos
Crear la carpeta "registrar" en "C:Xampp/htdocs/registar"
descargar y copiar los archivos: index,procesar, styles y  usuarios en la carpeta C:Xampp/htdocs/registar
ingresar a http://localhost/registro/index.html
validar el proyecto
